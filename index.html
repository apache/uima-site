Unstructured Information Management Architecture

Build and run analysis pipelines for text and other unstructured content.

Apache UIMA is the infrastructure for analysis applications: a common data structure, the CAS, a type system describing what goes into it, and a framework that combines, configures and runs analysis components. The components themselves you write, or take from the collections built on UIMA.

Read the documentation Get UIMA {{ uimaj.version }}

UIMA Java SDK

The framework: type systems, the CAS, analysis engines, aggregates, collection processing and the uimaFIT API for writing your own components in plain Java.

UIMA Ruta

A rule language for writing your own annotators quickly, with an Eclipse workbench to develop, explain and test rules.

Components and tools

Ready-made analysis components come from collections such as Apache OpenNLP, DKPro Core and Apache cTAKES; GitHub lists over 900 repositories depending on the Java SDK.

How UIMA works

An application is split into components, for example sentence detection, tokenization and named entity recognition. Each component implements a framework interface and describes its inputs, outputs and parameters in metadata. The framework runs the components and moves the data, a CAS holding the document and all annotations made on it, between them.

The UIMA SDK provides this infrastructure, not the analysis itself: apart from examples, it ships no tokenizers, taggers or entity recognizers. You bring those, either by writing your own, as Java classes with uimaFIT or as Ruta rules, or by using components from the ecosystem, for example the UIMA integration of Apache OpenNLP or the wrappers for many NLP tools in DKPro Core. Components from different sources work together as long as they agree on a type system.

Since version 3 the Java framework integrates tightly with modern Java, for example with Java streams over annotations through the select API, and is designed for performance on current hardware.

Apache UIMA implements the OASIS UIMA specification.
