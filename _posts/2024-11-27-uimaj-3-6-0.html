--- title: "Apache UIMA Java SDK (incl. uimaFIT) 3.6.0 released" render_with_liquid: false ---

The Apache UIMA team is happy to announce the release of the Apache UIMA Java SDK 3.6.0. Since this version, uimaFIT is part of the UIMA Java SDK release. The code repositories have also been merged. This marks the end of Apache uimaFIT as a separate release. For the time being, the uimaFIT Maven artifacts continue to be released under the usual coordinates.

Please see the the complete list of issues fixed (alternative) for more details of the changes.
