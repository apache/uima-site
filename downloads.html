Downloads

Maven

Most people use UIMA through the artifacts on Maven Central. For the core framework alone:

<dependency>
  <groupId>org.apache.uima</groupId>
  <artifactId>uimaj-core</artifactId>
  <version>{{ uimaj.version }}</version>
</dependency>

When you use more than one module of the UIMA Java SDK, for example uimaFIT or the JSON support, import the BOM (bill of materials) once and leave the versions out of the individual dependencies. The BOM keeps all UIMA modules on the same release: 

<dependencyManagement>
  <dependencies>
    <dependency>
      <groupId>org.apache.uima</groupId>
      <artifactId>uimaj-bom</artifactId>
      <version>{{ uimaj.version }}</version>
      <type>pom</type>
      <scope>import</scope>
    </dependency>
  </dependencies>
</dependencyManagement>

<dependencies>
  <dependency>
    <groupId>org.apache.uima</groupId>
    <artifactId>uimaj-core</artifactId>
  </dependency>
  <dependency>
    <groupId>org.apache.uima</groupId>
    <artifactId>uimafit-core</artifactId>
  </dependency>
</dependencies>

The BOM covers the UIMA Java SDK modules (uimaj-*, uimafit-*, jVinci) and is available since 3.5.0. With Gradle, use it as a platform: 

dependencies {
  implementation(platform("org.apache.uima:uimaj-bom:{{ uimaj.version }}"))
  implementation("org.apache.uima:uimaj-core")
  implementation("org.apache.uima:uimafit-core")
}

See all UIMA artifacts on Maven Central.
